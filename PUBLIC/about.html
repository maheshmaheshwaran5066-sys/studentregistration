PROJECT OVERVIEW

From Form → API → Database → Management System

This project started as a basic student registration form. Instead of keeping the submitted information only inside the browser, we built a complete backend system capable of receiving, validating, storing, retrieving, updating and deleting student records.

The final application contains a registration interface, student dashboard, search functionality, individual student profiles, editing functionality, deletion functionality and a MongoDB database.

Final Result A complete CRUD-based full-stack Student Management System.

DEVELOPMENT JOURNEY

How we progressed

The project was developed incrementally. Each stage introduced another part of the full-stack architecture.

01

Project Initialization

Created the project directory and initialized Node.js using npm.

npm init -y
02

Installed Backend Dependencies

Installed Express, Mongoose, dotenv, CORS and Nodemon.

npm install express mongoose dotenv cors

Created the Express Server

Built server.js and created the backend server using Express.js.

04

Connected MongoDB

Added the MongoDB connection string to the environment configuration and connected MongoDB through Mongoose.

Created Student Model

Designed the complete student schema containing personal, academic, address, parent and additional details.

Added Validation

Added required fields, unique fields, email validation, phone validation, Aadhaar validation, pincode validation and enum restrictions.

Created a multi-section student registration form using HTML and CSS.

Built Student Dashboard

Added an individual profile page that retrieves a student using their MongoDB document ID.

DEBUGGING & FIXES

Things we encountered and fixed

The project wasn't built perfectly on the first attempt. Several real development issues appeared during implementation and were resolved along the way.

01

Invalid package.json

npm initially reported a JSON parsing error because the package.json file was empty or malformed. The project was reinitialized and the package configuration was corrected.

02

Missing MongoDB URI

The MongoDB connection initially failed because the environment configuration did not contain the required MONGO_URI. The .env configuration was corrected.

03

Router Export Placement

The router export was accidentally placed before all routes were defined. It was moved to the bottom of studentRoutes.js.

04

Schema Validation

Validation rules were added and tested for fields including email, phone number, Aadhaar number and pincode.

05

Optional Empty Fields

Optional fields containing empty strings could trigger validation problems. The frontend was adjusted to send undefined for blank optional values.

06

Frontend / Backend Integration

The frontend was progressively connected to the REST API using JavaScript Fetch requests.

07

CRUD Verification

POST, GET, PUT and DELETE operations were individually tested using Postman before being used by the frontend.
